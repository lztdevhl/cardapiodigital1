==================================================

Este projeto é o cardápio digital da:

Jantinha do Rogério

NÃO É IFOOD.
NÃO É DELIVERY.

Não existem:
- carrinho;
- botão de comprar;
- checkout;
- pagamento;

- pedido;
- endereço de entrega.

QR Code
→ abre cardápio
→ navega pelas categorias
→ vê pratos
→ vê fotos
→ vê descrição
→ vê preço
→ toca em um item para ver detalhes
