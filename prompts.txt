Quero que você desenvolva uma aplicação web completa de CARDÁPIO DIGITAL para um estabelecimento chamado:

"Jantinha do Rogério"

IMPORTANTE:
Este sistema NÃO é um delivery.
NÃO quero criar um clone de iFood.
NÃO quero carrinho.
NÃO quero pedidos.
NÃO quero checkout.
NÃO quero pagamentos.
NÃO quero cálculo de entrega.

O objetivo do projeto é exclusivamente permitir que clientes que estejam sentados nas mesas do estabelecimento acessem o cardápio pelo celular, através de um QR Code, visualizem as comidas, bebidas, preços, fotos e descrições.

O estabelecimento também precisa de uma área administrativa privada em /admin para controlar completamente o conteúdo do cardápio.

==================================================
1. STACK
==================================================

Utilize:

- Next.js com App Router
- TypeScript
- Tailwind CSS
- Prisma ORM
- PostgreSQL
- Cloudinary para armazenamento das imagens dos produtos
- bcrypt para hash de senha
- autenticação segura utilizando sessão/cookie httpOnly

Não utilize Supabase.

Estruture o projeto de forma profissional e preparada para deploy na Vercel.

Não use dados mockados hardcoded no frontend.

Todas as informações de produtos e categorias exibidas no cardápio público devem vir do PostgreSQL.

- informar erro se falhar;
- impedir envio duplicado.
